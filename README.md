# 后羿之弓（Hou Yi's Bow）

Minecraft 1.21.1 NeoForge 模组。它新增一把独立的 **后羿之弓**；原版普通弓及其数值、拉弓时间、弹道均保持原版行为。

当前版本：**1.0.6**

## 版本迭代规则

- 独立“后羿之弓”基线版本为 **`1.0.1`**；当前修复版本为 **`1.0.6`**。
- 每完成一次常规更新，默认自动递增末位小版本号：`1.0.1` → `1.0.2` → `1.0.3` → `1.0.4` → `1.0.5` → `1.0.6`。
- 中版本号和大版本号可按变更性质提升：新增兼容功能或较大功能扩展可提升中版本号；存在破坏兼容的重大变更可提升大版本号。

## 兼容环境

- Minecraft **1.21.1**

- Java **21**

不支持 Forge、Fabric 或其他 Minecraft 版本。

## 获取方式

在锻造台按以下顺序放入材料：

| 模板槽 | 基础槽 | 添加槽 | 结果 |
| --- | --- | --- | --- |
| 下界合金升级模板 × 3 | 普通弓 × 1 | 下界合金锭 × 12 | 后羿之弓 × 1 |

配方会保留原弓的耐久、名称和附魔。锻造台界面只显示三个槽位，模组会在取出成品时精确扣除上述数量；任意材料不足时不会产生成品。

## 后羿之弓机制

- 默认耐久 **1000**。
- 基础满蓄力为 **10 game ticks**，20 TPS 时约 **500ms**。
- 每次射出至少 **3 支箭**，三支箭使用完全相同的准星方向，不再有多箭随机偏移。
- 每 3 支箭消耗 1 点耐久：3 支扣 1，4–6 支扣 2，…，12 支扣 4。
- 箭速为原版弓箭同等蓄力下的 **3.5 倍**；速度同步已针对高速箭处理。
- 箭的伤害、Power、火矢、无限、耐久等仍走原版箭矢判定；视觉使用原版**光灵箭**模型，但不会给命中目标附加发光或任何额外 Buff。
- 自带等同原版 **Punch IV** 的基础击退；额外 Punch 附魔仍按原版规则叠加。
- 同一次射击仅第一支实际生成的箭带有原版火箭火花拖尾，**不播放火箭声音**；命中实体或方块后停止继续产生拖尾。
- 后羿箭插入方块后最多保留 **100 tick**，20 TPS 下约 **5 秒**，随后自动清理。
- 满蓄力射击会播放低音量（0.35）的原版监守者音波声音，并发出由浅金、金、琥珀、深金交替组成的原版监守者光波。

## 附魔兼容

后羿之弓同时被识别为原版弓和弩可附魔物品，因此可沿用：

- 弓系：力量、冲击、火矢、无限、耐久、经验修补等；
- 弩系：快速装填、多重箭、穿透。

快速装填的拉弓时间为：无附魔 10 tick、I 级 8、II 级 6、III 级 4、IV 级及更高均为 **2 tick**；高等级不会低于 2 tick。

多重箭以 3 支为基础增加数量，单次最多 **12 支**，且所有箭保持同一方向。高等级快速装填 / 多重箭由其他 Mod、数据包或命令加入时同样会遵守 2 tick / 12 支上限。多重箭与穿透之间仍保留原版弩附魔的互斥规则，不额外强化。

## 与旧数据包的关系

本模组已把原先用于多重箭表现与耐久的逻辑整合到后羿之弓中。确认本 Mod 在目标实例正常加载并完成锻造、射击测试后，可以删除实例 `datapacks/` 中旧的 `LS-Multishot-Durability-Fix-1.21.1.zip`，无需保留两个实现。

## Northstar 首帧兼容

当客户端同时安装 Northstar 时，后羿之弓会在单人世界的集成服务器尚未就绪期间，暂时跳过 Northstar 的行星天空渲染；服务器就绪后立即恢复。该保护用于避免 Northstar 过早读取 SERVER 配置的崩溃，且不修改、禁用或替换 Northstar、Sable、Connector、ModernFix 或加载屏 Mod。

## 安装

1. 安装 Minecraft 1.21.1 和 NeoForge 21.1.233（或兼容的 21.1.x）。
2. 将构建出的 `houyis-bow-1.0.6.jar` 放入游戏实例的 `mods/` 目录。
3. 客户端与服务端建议安装相同版本，以正确显示高速箭、金色音波和光灵箭外观。
4. 进入游戏后通过锻造台制作“后羿之弓”。

请不要同时保留功能相同的旧测试 JAR，以免混淆加载结果。

## 从源码构建

需要 JDK 21：

```bash
./gradlew build
```

构建产物：

```text
build/libs/houyis-bow-1.0.6.jar
```

运行单元测试：

```bash
./gradlew test
```
