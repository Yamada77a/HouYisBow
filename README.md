# 后羿之弓（Hou Yi's Bow）

一个专注于强化原版弓手感的 Minecraft NeoForge 模组。

当前公开版本为 **0.0.1**。本版本只适配：

- Minecraft **1.21.1**
- NeoForge **21.1.233**（同一 21.1.x 分支）
- Java **21**

> 不支持 Forge、Fabric，也没有声明兼容其他 Minecraft 版本。

## 0.0.1 功能

- 弓箭离弦速度提高到原来的 **3 倍**。
- 弓在 **4 game ticks** 达到满蓄力；服务器保持 20 TPS 时约为 **200ms**。
- 箭的实际飞行方向对齐射手准星，取消随机散布。
- 满蓄力射击时播放一次原版烟花发射声，并生成原版烟花粒子。
- 为超过原版实体速度包上限的高速箭提供精确位置与速度同步，降低客户端侧偏、慢速后跳等显示问题。
- 对多箭机制产生的每支弓箭分别生效，但本仓库**不包含**任何多重箭数据包。

## 重要说明

- “后羿之弓”目前是模组名称；**0.0.1 不会新增一把独立物品**，而是全局调整由原版 `BowItem` 射出的箭。
- 三倍真实箭速会影响原版按速度计算的伤害，本版本没有额外做伤害补偿。
- 200ms 按 20 TPS 计算；服务器卡顿时，现实时间可能更长。
- 单人游戏直接安装即可。多人游戏建议服务端与客户端安装同一版本，以获得正确的高速箭显示和 4 tick 拉弦动画。
- 这是首个公开版本，当前组合仍需要更多实际游戏与联机测试。

## 安装

1. 安装 Minecraft 1.21.1。
2. 安装 NeoForge 21.1.233 或同一 21.1.x 分支的兼容版本。
3. 将 `houyis-bow-0.0.1.jar` 放入实例的 `mods/` 目录。
4. 启动游戏，在 Mod 列表中确认出现 **Hou Yi's Bow**。

请不要同时保留名称不同但功能相同的旧测试版 JAR，以免事件重复执行。

## 从源码构建

需要 JDK 21：

```bash
./gradlew build
```

构建产物位于：

```text
build/libs/houyis-bow-0.0.1.jar
```

运行测试：

```bash
./gradlew test
```

项目基于 NeoForge 官方 1.21.1 ModDevGradle 模板整理，可在全新环境中解析依赖并独立构建。
