# 后羿之弓 1.0.1

这是 **Hou Yi's Bow（后羿之弓）** 的独立物品基线版本。

## 主要内容

- 普通原版弓不再被改动；使用锻造台制作独立的后羿之弓。
- 配方：下界合金升级模板 × 3、普通弓 × 1、下界合金锭 × 12。
- 耐久 1000，基础满蓄力 10 tick，基础一发 3 支同向箭。
- 快速装填最低 2 tick；多重箭每次最高 12 支；每 3 支箭扣 1 耐久。
- 3.5 倍箭速、光灵箭视觉（无发光 Buff）、原版火矢 / 无限 / 穿透 / 耐久机制。
- 无声原版火箭火花拖尾，以及低音量监守者音波声和交替金色音波。

## 兼容范围

- Minecraft 1.21.1
- NeoForge 21.1.233 / 21.1.x
- Java 21

不支持 Forge、Fabric 或其他 Minecraft 版本。

## 迁移

该版本已覆盖旧多重箭表现数据包的目标功能。验证 Mod 正常运行后，可从游戏实例移除旧的 `LS-Multishot-Durability-Fix-1.21.1.zip` 数据包。
