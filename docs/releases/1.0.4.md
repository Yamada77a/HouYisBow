# 后羿之弓 1.0.4

## 修复

- 修复 1.0.3 在 Northstar 天空渲染时触发的 `IllegalClassLoadError`。
- 删除位于 Mixin 专用包中的普通 `NorthstarStartupGuard` 类，将服务器就绪判断直接内联到私有注入处理器。
- 保留仅客户端、仅本地集成服务器未就绪/停止期间生效的 Northstar 保护；远程多人和服务器正常运行后的渲染不受影响。
- 不修改、禁用或替换 Northstar、Connector、Force Close Loading Screen 或其它实例 Mod。
