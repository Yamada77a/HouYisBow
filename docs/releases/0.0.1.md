# 后羿之弓 0.0.1

这是 **Hou Yi's Bow（后羿之弓）** 的首个公开版本。

## 主要内容

- 箭速提高到原来的 3 倍；
- 满蓄力缩短至 4 game ticks，20 TPS 下约 200ms；
- 箭沿准星方向飞行；
- 满蓄力加入原版烟花声音与粒子；
- 修正高速箭在客户端可能出现的方向偏差和首次同步问题。

## 兼容范围

- Minecraft 1.21.1
- NeoForge 21.1.233 / 21.1.x
- Java 21

不支持 Forge、Fabric 或其他 Minecraft 版本。

## 注意

0.0.1 不新增独立弓物品，而是调整原版弓的射击行为；本发布包也不包含多重箭数据包。
