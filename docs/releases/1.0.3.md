# 后羿之弓 1.0.3

## 修复

- 修复锻造配方在进入世界同步时使用了两个不同对象、导致 `update_recipes` 包编码失败的问题。
- 修复 Northstar 可选客户端兼容 Mixin 的方法可见性错误，使其可以在目标实例正常应用。
- Create / BetterStats 的配置异常是前述配方同步断开后、服务端配置已卸载时触发的下游连锁；本版本通过修复断开源头处理它，不修改任何其它 Mod。

## 验证范围

- Minecraft 1.21.1 / NeoForge 21.1.233 / Java 21。
- 保留完整目标实例的全部 Mod，创建新世界、进入已有世界并退出世界。
