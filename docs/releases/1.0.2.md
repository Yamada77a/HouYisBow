# 后羿之弓 1.0.2

## 修复

- 新增可选的 Northstar 客户端兼容保护，不需要把 Northstar 加为编译依赖。
- 在单人世界的集成服务器尚未准备完成、或开始停止时，暂时跳过 Northstar 行星天空渲染，避免其读取未加载的 SERVER 配置。
- Northstar、Sable、Connector、ModernFix、Force Close Loading Screen 及其它实例 Mod 均保持原样。

## 验证范围

- Minecraft 1.21.1 / NeoForge 21.1.233 / Java 21。
- 需在包含 Northstar 0.6.4、Sable 2.0.3、Connector beta15、ModernFix 与 Force Close Loading Screen 的目标实例中创建和进入世界验证。
